# DOIT
### Some notes on AI usage:
This is primarily a learning (and personal) project I've been working on for
some time, and most of the frontend is written with claude. The backend is
entirely written and designed by me (yay!) with feedback and code checking from claude/chatgpt.

(Documentation generated by claude)

A lightweight TODO desktop app for developers and project managers. Tasks,
calendar, a pomodoro focus timer, and a dependency graph — in one small native
window, with everything stored locally.

Built with [Tauri 2](https://tauri.app) (Rust backend) + React 19 + TypeScript.

> **Status: work in progress.** All five screens render, but they still read
> in-memory mock data. The Rust storage layer (SQLite, migrations, task CRUD)
> is written and tested; the `#[tauri::command]` wrappers that connect the two
> halves are the current task. See `project-plan.md` for the full roadmap.

## Screens

| Page | What it does |
| --- | --- |
| **Tasks** | List and table views, status filters, detail pane, tags, dependencies |
| **Calendar** | Week / month views, drag tasks onto a slot to schedule them |
| **Focus** | Pomodoro timer with interruption logging |
| **Graph** | Whiteboard of draggable task nodes showing what blocks what |
| **Settings** | Calendar accounts, export, app preferences |

Press `1`–`5` to switch pages; the command palette is `Cmd/Ctrl+K`.

## Getting started

Needs [Node](https://nodejs.org) and the
[Rust toolchain](https://rustup.rs) plus Tauri's
[system dependencies](https://tauri.app/start/prerequisites/).

```bash
npm install
npm run tauri dev      # run the desktop app
```

Other commands:

```bash
npm run tauri build    # bundle release binaries
npm run dev            # vite only, in a browser at :1420 (no backend)
npm run build          # typecheck + production build
cargo test             # from src-tauri/ — backend tests
```

## How it's put together

Two processes in one bundle. The frontend (`src/`) renders the webview and
talks to the backend only through `invoke("command_name", args)`. The backend
(`src-tauri/src/`) owns the data:

```
src/
  data/store.tsx     app state — the single seam where data enters the UI
  data/mock.ts       placeholder data, deleted once the backend is wired
  types.ts           shapes both sides agree on
  pages/             one file per screen
  styles/            design tokens + app chrome

src-tauri/src/
  lib.rs             app setup, managed DB state, command registry
  db/                connection, pragmas, forward-only migrations
  model.rs           Rust mirror of types.ts
  tasks.rs           task logic as plain fns over &Connection (tested)
  command.rs         thin #[tauri::command] wrappers
  error.rs           AppError — serializable, so invoke rejects cleanly
```

Data lives in SQLite at the platform app-data dir
(`~/.local/share/com.bryan.doit/doit.sqlite3` on Linux), created on first run.
No account, no server, no sync.
